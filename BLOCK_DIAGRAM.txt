================================================================================
SMART PORT MANAGEMENT SYSTEM - ARCHITECTURE BLOCK DIAGRAM (DAG)

═══════════════════════════════════════════════════════════════════════════════
LAYER 1: FRONTEND PAGES (served on port 5500 via python3 http.server)
═══════════════════════════════════════════════════════════════════════════════

  login.html           ─── entry point, email/password + mock login
    │
    ├──► dashboard.html       ─── KPIs, charts, alerts, recent activity
    ├──► ships.html           ─── vessel list/search/filter/pagination + register
    ├──► containers.html      ─── container list/search/filter/pagination + add
    ├──► trucks.html          ─── truck list, export, view/edit/track
    ├──► berths.html          ─── berth list with assign/release modals
    ├──► security.html        ─── alerts list + export, view/edit/resolve
    ├──► profile.html         ─── user profile view/edit
    ├──► billing.html         ─── invoice CRUD with line items
    ├──► reports.html         ─── report generation + download
    ├──► maintenance.html     ─── equipment + maintenance schedules
    └──► environment.html     ─── air/water/noise/weather monitoring

  Each page loads JS in this order:
    utils.js → config.js → store.js → app.js → (page-specific inline script)


═══════════════════════════════════════════════════════════════════════════════
LAYER 2: FRONTEND JAVASCRIPT LAYER
═══════════════════════════════════════════════════════════════════════════════

  utils.js (NO dependencies)
    ├── Utils.formatNumber(n)
    ├── Utils.formatDate(d)
    ├── Utils.timeAgo(d)
    ├── Utils.generateId()
    ├── Utils.debounce(fn, ms)
    ├── Utils.paginate(arr, page, perPage)
    └── Utils.searchFilter(arr, query, fields)

  config.js (depends on: utils.js)
    ├── API_BASE_URL = 'http://127.0.0.1:5001/api/v1'
    ├── MOCK_USERS = { 'superadmin@smartport.gov.in': {...}, ... }
    └── class Api
        ├── Api.login(email, password) → tries API, falls back to mock
        ├── Api.request(endpoint, options)
        ├── Api.get(endpoint)
        ├── Api.post(endpoint, data)
        ├── Api.put(endpoint, data)
        └── Api.delete(endpoint)

  store.js (depends on: utils.js)
    ├── localStorage CRUD with 10 collections
    ├── Store.init() → loads or seeds demo data
    ├── Store.get(collection) / Store.add / Store.update / Store.remove
    ├── Store.getShipStats()
    ├── Store.getContainerStats()
    ├── Store.getTruckStats()
    ├── Store.getDashboardKPIs()
    └── Store.getUser()

  app.js (depends on: utils.js, config.js, store.js)
    ├── App.showToast(message, type)
    ├── App.createModal(options)
    ├── App.exportCSV(data, filename)
    ├── App.initSearch()
    ├── App.initUserDisplay()
    ├── App.initNotifications()
    ├── App.editProfile()
    ├── App.saveProfile()
    ├── App.exportTrucks()
    ├── App.exportSecurity()
    ├── App.exportBerths()
    ├── App.showAddTruckModal()
    ├── App.submitAddTruck()
    ├── App.showAddAlertModal()
    ├── App.submitAddAlert()
    ├── App.showAddScheduleModal()
    └── App.submitAddSchedule()

  charts.js (depends on: Chart.js CDN)
    └── Chart.js initialization helpers

  login.js (depends on: config.js)
    └── Login page handler + mock auth fallback
